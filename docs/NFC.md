# NFC名刺への書き込み

## 書き込むURL
```
https://○○.pages.dev/?via=nfc
```
（QRコードには `?via=qr` を付けると、管理画面でどちらから来たか分かる）

## 手順（iPhone / Android）
1. 「NFC Tools」などの書き込みアプリを入れる
2. 「書く」→「レコードを追加」→「URL/URI」→ 上のURLを入力
3. 「書き込む」→ カードをスマホの上部（iPhone）／背面中央（Android）に当てる
4. 別のスマホでかざして、サイトが開くか確認

## 注意
- **ロック（書き込み禁止）はしない**。URLを変えたくなったら書き直せるように
- iPhoneはロック画面でも反応するが、出てくる通知をタップしてもらう必要がある
- Androidは画面ロック解除とNFCオンが必要。反応しない人のために、名刺の裏にQRコードも入れておくと安心
- 金属の上や金属ケース越しだと読めないことがある
