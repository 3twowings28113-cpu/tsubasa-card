# GenCode での育て方

v1 は実装済み（SPEC.md の仕様どおり）。GenCode は「直す・足す」に使う。
`tsubasa-card` フォルダで `gencode` を起動して、下の指示を貼る。

## まず全体を把握させる
```
CLAUDE.md と SPEC.md を読んで、このリポジトリの構成と、各ファイルの役割を短く説明してください。まだ何も変更しないでください。
```

## 受け入れチェック
```
SPEC.md §7 の受け入れチェックを1から順に確認して、満たしていないものを表にしてください。直す前に一度見せてください。
```

## 機能を足す例
```
「名刺画像を保存」機能を足してください。public/assets/brand/ に名刺の表面画像（91:55）を作り、site.json の cardImage にパスを入れると連絡先ボックスにリンクが出るようにしてください（SPEC.md §4-3）。
```
```
出会いの羽根で、羽根をタップしたときの吹き出しを、翼の上のその羽根の近くに出すようにしてください。スマホでも押しやすく。
```

## 直すときのコツ
- 見た目 → 「SPEC.md §2 のトークンを守って」と添える
- 演出 → 「transform と opacity だけで動かして」と添える
- 終わったら `npm run deploy` で公開に反映
